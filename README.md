# Таскер

Таскер для небольшой команды (интерфейс на украинском): задачи, проекты, календарь и статистика. Все участники видят изменения друг друга сразу, без перезагрузки страницы.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. При первом запуске впишите имена участников, потом каждый выбирает себя на своём устройстве.

Чтобы коллеги в той же сети зашли со своих компьютеров, дайте им адрес из строки `Network:` в терминале, например `http://192.168.0.104:5173`.

### Постоянный сервер

```bash
npm run build
npm start                         # http://localhost:3001
TASKER_PASSWORD=секрет npm start  # общий пароль для команды, логин: team
```

Данные хранятся в `data/`: база SQLite и загруженные файлы. Для бэкапа достаточно скопировать эту папку. Другое место можно задать через `DATA_DIR=/путь`.

В Docker (подойдёт любой VPS, Railway, Render, Fly):

```bash
docker build -t tasker .
docker run -p 3001:3001 -v tasker-data:/data -e TASKER_PASSWORD=секрет tasker
```

### Vercel

На Vercel нет постоянного диска, поэтому там таскер хранит данные в Postgres, а файлы — в Vercel Blob. Синхронизация между участниками идёт опросом сервера каждые 4 секунды.

1. Импортируйте репозиторий в Vercel (New Project → GitHub). Настройки сборки подтянутся из `vercel.json`.
2. Storage → подключите **Neon** (Postgres) — появится переменная `DATABASE_URL`.
3. Storage → создайте **Blob** store (public) — появится `BLOB_READ_WRITE_TOKEN`.
4. По желанию добавьте `TASKER_PASSWORD` в Environment Variables.
5. Сделайте Redeploy. Таблицы в базе создадутся сами при первом запросе.

Локально тоже можно работать с Postgres: `DATABASE_URL=... npm run dev`.

## Что умеет

- **Участники.** На входе показывается команда, участников можно добавлять. Можно смотреть задачи любого участника: «Мои», «Все» или конкретный человек.
- **Задачи.** У каждой задачи есть исполнитель и автор, статус (не сделана / сделана / отменена), приоритет, теги и описание.
- **Сроки.** Задачу можно поставить на день, неделю, месяц или без срока. Дедлайн с точным временем задаётся отдельно.
- **Пункты и подпункты.** Чек-лист с вложенностью и прогрессом, отдельно — счётчик шагов («3 из 10»).
- **Файлы и фото** можно прикрепить к задаче, проекту, комментарию и к профилю. Скриншот вставляется в открытую задачу через ⌘V. Для фото делаются превью, есть просмотр на весь экран.
- **Виды:** день, неделя, месяц, все задачи. Группировка по срокам, проектам, людям или статусу, фильтры и поиск.
- **Календарь** на месяц и неделю. Задачи перетаскиваются между днями, задачи на неделю и месяц показываются отдельной полосой.
- **Перетаскивание:** порядок внутри списка, перенос между днями и секциями. Если бросить задачу на человека в боковой панели, она назначится на него, а если на проект — перенесётся в этот проект.
- **Проекты** с описанием, файлами и прогрессом. Задачи можно вести и без проекта.
- **Статистика:** сколько закрыто за период и сравнение с прошлым, график по дням, таблица по людям (сделал, отменил, поставил, просрочено, доля в срок), загрузка на 7 дней, кто кому ставит задачи, прогресс проектов и лента событий.

### Что добавлено сверху

- **Быстрый ввод одной строкой.** Например, «Надіслати КП завтра о 11:30 @аня #сайт !!» — дата, время, исполнитель, проект и приоритет разбираются сами. Таскер понимает «до пʼятниці», «через 3 дні», «на тиждень», «у листопаді», «щопонеділка», «по буднях».
- **Повторяющиеся задачи.** Когда отмечаете такую задачу сделанной, следующая создаётся сама.
- **Живая синхронизация** и индикатор «кто в сети». Если вам поставили задачу, появится уведомление со ссылкой на неё.
- **Отмена действий.** «Вернуть» в уведомлении или ⌘Z — после удаления, закрытия или отмены задачи.
- **Работа с клавиатуры:** `N` — новая задача, `⌘K` — поиск и команды, `1–6` — разделы, `←/→` — листать период, `X` — отметить, `?` — все клавиши.
- **Комментарии и история** изменений у каждой задачи.
- Светлая и тёмная тема, мобильная вёрстка.

## Устройство

- `server/app.mjs` — API на Hono. Локально: SQLite (`node:sqlite`), файлы на диске, Server-Sent Events. На Vercel (`api/index.mjs`): Postgres, Vercel Blob, опрос.
- `src/` — React + TypeScript + Vite, состояние в zustand. Изменения применяются в интерфейсе сразу, ещё до ответа сервера.
